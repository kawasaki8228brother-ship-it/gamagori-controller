# iPhone private capture procedure — proposed, UNVERIFIED

This is a preparation document. No actual official HTML has been obtained by Codex, no private Drive file was opened, and these iPhone screen steps have not been executed or verified. Perform only while safely parked. A separate approval, a designated operator and an independently checked private account/folder are prerequisites.

1. Open Shortcuts (ショートカット) on the iPhone. Tap the plus button to create a new shortcut and choose a locally identifiable name.
2. Add a Text (テキスト) action containing the independently approved official raceindex URL. A public URL template is https://www.boatrace.jp/owpc/pc/race/raceindex?hd=YYYYMMDD&jcd=07 . The date must be the intended JST day; do not substitute an unverified day or retain authentication/query secrets.
3. Add Get Contents of URL (URLの内容を取得). Set the method to GET. Do not add a login, account token, cookie export or credentials.
4. Preserve the returned file/data output. Do not use Get Text from Input, rich-text conversion, translation, webpage-reader extraction or copy/paste of a rendered page: these can change bytes. Whether Get Contents of URL actually exposes unchanged response bytes on the device is UNVERIFIED.
5. Add Set Name (名前を設定) for a new .html filename that identifies capture day and local capture time. Do not overwrite an existing file. The name is an operator aid, not proof of server time or original bytes.
6. Add Save File (ファイルを保存). Keep Ask Where to Save (保存先を尋ねる) enabled; exact localized labels depend on iOS and remain UNVERIFIED. At execution, select Files and the already approved private Drive folder if the Google Drive Files provider is available. Do not choose a public/shared folder. Files-provider availability, data-preserving behavior and upload success are UNVERIFIED. If the approved private Drive provider is unavailable, STOP; do not silently substitute another destination.
7. Before running, inspect every action and the selected URL/account/folder. Run once only while parked. If the action asks to authenticate unexpectedly or produces a rendered/text-converted item, STOP and retain the uncertainty rather than pretending it is raw capture.
8. In Files/Drive, verify that a new file exists under the intended private account/folder and is not publicly shared. Do not send screenshots of account lists, environment values, credentials or the document body.
9. HQ14 records operator, requested JST date, device-observed capture start/end times, timezone, original filename, local byte count if exposed, private Drive ID, upload/readback receipt and any redirect/error observations in a private sidecar. Unknown fields remain null/UNVERIFIED. A filename timestamp is not server timestamp evidence.
10. After private Drive readback, Claude computes raw-file bytes/SHA and compares the old/v003 parser using the prepared local checker. The SHA identifies the saved artifact; it does not alone prove that Shortcuts preserved original network bytes, that the URL was genuinely official or that transport framing completed.
11. Share only the safe comparison summary and evidence references approved for disclosure. Do not upload HTML, URLs with credentials, headers, private Drive IDs/account identifiers or original real-race data to the public repository.

Content-Length, wire bytes, decoded bytes, HTTP status, redirects, stream completion and document-end evidence cannot be inferred from this workflow unless separately measured. The current iPhone procedure does not assert that those observations are available. A failed request, unavailable provider, text conversion or uncertain upload/readback is BLOCKED_EXTERNAL.

Shortest completion path: Andy/HQ14 approves operator and private destination → operator performs one capture and private readback → Claude compares bytes/SHA/parser summaries and reviews the unresolved forms. There is no automatic acceptance, replay, task change, source connection or deployment.
